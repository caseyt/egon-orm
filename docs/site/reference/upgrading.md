# Upgrading

How to move from one version to the next when a release changes something you have to act
on: a renamed function, a changed default, a behaviour that now throws. Each section names
the versions, what changed, why, and what to change in your code.

Nothing has been released yet, so there is nothing to upgrade from. The first section will
appear with the first release that needs one; the [Changelog](/reference/changelog) links
to it.
